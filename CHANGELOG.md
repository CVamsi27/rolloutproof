# Changelog

## 0.1.0-alpha.1 — 2026-11-06

Keep injected observations simulated and freeze the rollback sequence. Add read-only scenario and image preflight to `doctor`, plus a GitHub installation and trial guide.

## 0.1.0-alpha.0 — 2026-11-05

First public alpha source release.

Four PostgreSQL/application rollout combinations, rollback against newly written data, separate migration observations and an isolated bridge gateway.

Verification and platform limits are documented. No production-safety, uniqueness, time-saving or retained-adoption claim is made. GitHub distribution is separate from npm registry publication.
