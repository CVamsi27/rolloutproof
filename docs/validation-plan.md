# Rolloutproof validation plan

This is an independently installable local prototype. Technical synthetic proofs and current gates are recorded in [verification](verification.md). Runtime success does not establish developer demand or productivity savings.

Continue only after five independent developers trial this project, three integrate it successfully and two retain it for a later change. Record setup time, assistance, actionable findings and reasons for removal. Current evidence: zero participants, zero independent integrations, zero retained uses. No automatic outreach or publication.

Keep synthetic broken/fixed controls and the existing-tool comparison reproducible with `npm run measure`. Use the package README for exact scope, limitations and alternatives. Prefer an upstream contribution when an existing project already supplies the core capability.
